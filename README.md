# Битоника

Веб-синтезатор, который объединяет город и природу в одну музыкальную среду:
два мелодических голоса, двадцать звуков окружающего пространства и клубный ритм.
Всё звучание создаётся программно через **Tone.js 15.1.22** — без аудиозаписей.

Технологии: HTML, CSS, обычный JavaScript (ES-модули), Tone.js. Без React, сборки и сервера.

---

## Как запустить

Сайт нужно открывать **через локальный сервер**, а не двойным щелчком по файлу:
браузер не загружает JS-модули и SVG-иконки по адресу `file://`.

Любой из способов:

- **VS Code** → расширение *Live Server* → «Open with Live Server» на `index.html`;
- **терминал** в папке проекта:
  ```bash
  python3 -m http.server 8000
  ```
  и открыть <http://localhost:8000>.

Звук включается только после нажатия ▶ (так требуют браузеры).

### Проверки

- `node tests/state.test.mjs` — 29 проверок настроек, ссылки и парных ползунков
  (то же в браузере: `tests/tests.html`);
- `tests/audio-check.html` — измерение каждого из 20 звуков среды (≈25 секунд).

| `css/style.css` | весь внешний вид, CSS-переменные, адаптивность |
| `js/state.js` | **единый объект настроек**: начальное состояние, проверка данных, ссылка, логика парных ползунков |
| `js/audio.js` | весь звук: голоса, 20 звуков среды, барабаны, эффекты, общий выход, Play/Pause |
| `js/patterns.js` | пять барабанных рисунков и правило плотности |
| `js/recorder.js` | запись итогового звука в WAV |
| `js/controls.js` | ползунки, крутилки и переключатели (создание и обработка мыши/касания/клавиатуры) |
| `js/main.js` | связывает интерфейс, состояние и звук; кнопки верхней панели |
| `js/vendor/tone-15.1.22.js` | Tone.js, сохранён в проекте (работает без интернета) |
| `assets/icons/icons.svg` | набор иконок (спрайт) |
| `assets/fonts/` | шрифт Inter |
| `tests/` | небольшие проверки |

**Главное правило кода:** любое действие пользователя сначала меняет объект `state`,
потом вызывает функцию обновления звука (`audio.updateVoice`, `audio.updateAmbience` …).
Поэтому интерфейс, звук, сброс и ссылка всегда используют одни и те же значения.
Начальные настройки описаны один раз — `DEFAULT_STATE` в `js/state.js`.

## Как устроен звук

```
голос «Город»   ─┐
голос «Природа» ─┤→ voicesBus ───┐
20 звуков среды ─→ ambienceBus ──┼→ master → fader → компрессор → лимитер → колонки
барабаны ───────→ drumsBus ──────┘  (общая   (пауза)                    ├→ точки в центре
                                     громкость)                         └→ запись WAV
```

- Все узлы и циклы создаются **один раз** в `initAudio()` после первого нажатия ▶.
  Play/Pause/Сброс только включают и выключают их — повторный старт не создаёт копий.
- Ревербераторы Tone.js готовят импульсный отклик асинхронно — код ждёт `reverb.ready`,
  пока на кнопке крутится индикатор загрузки.
- Все ритмические события висят на **одном** `Tone.Transport`: темп одинаково меняет
  мелодии, барабаны и ударные звуки среды. Эхо голосов тоже пересчитывается под темп.
- **Пауза** плавно (0,3 с) приглушает весь выход — вместе с хвостами эха и реверберации,
  затем останавливает транспорт, отпускает все ноты и приостанавливает запись.
- **Защита от перегрузки:** умеренные уровни каналов → компрессор → лимитер −1 дБ.
  Проверено: при всех слоях на максимуме пик выхода около −5 дБ.

### Мелодические голоса

Цепочка каждого голоса: **источник → искажение → эхо → реверберация → громкость канала → общий выход**.

| | Город (C3–C4) | Природа (C4–C5) |
|---|---|---|
| Источник | `Tone.MonoSynth`: фильтр с резонансом быстро открывается в начале ноты — звук низкий, упругий, с металлическим оттенком | `Tone.Synth`: плавная атака, долгое затухание, лёгкое вибрато — мягкий, воздушный |
| Эхо | `FeedbackDelay`, восьмая с точкой | `FeedbackDelay`, четверть |
| Реверберация | 2,2 с | 4,5 с |

Каждые восьмые ноты код читает из `state` включённые ноты: выключенная позиция — пауза.
Ползунок рядом с нотой — длительность звучания (10–100 % шага); сам шаг не меняется.
Форма волны меняет `synth.oscillator.type` у того же синтезатора — второй голос не создаётся.

**Эффекты** (функция `effectParams` в `audio.js`), значение крутилки 0…1:

| Крутилка | Что меняется |
|---|---|
| Эхо | доля повторов `wet = 0…0,55`, обратная связь `0,1…0,65` |
| Глубина | доля реверберации `wet = 0…0,75` |
| Искажение | сила перегрузки `distortion = 0,1…1`, при 0 эффект выключен |
| Плавность | скольжение между нотами `portamento = 0…250 мс` |

У каждого голоса свои значения (`state.voices.city.fx` и `state.voices.nature.fx`);
переключатель «Город / Природа» выбирает, какие из них показывают крутилки.

### Двадцать звуков среды

Каждый звук — небольшой «рецепт» в `createAmbience()` (`audio.js`). Непрерывные звуки
(шум, генераторы, медленные LFO) работают постоянно, их громкость регулирует ползунок.
Отдельные события (гудки, шаги, капли…) запускает `Tone.Loop` на общем транспорте —
пока звук выключен, события не создаются.

| № | Пара | Верх | Низ |
|---|---|---|---|
| 1 | Транспорт | машины: розовый шум, громкость и яркость фильтра вместе растут и падают (приближение/удаление), панорама гуляет | гудки: созвучия двух пилообразных тонов, одиночные и двойные |
| 2 | Люди | шаги: глухой низкий удар + короткое шуршание, каждую четверть, «левая/правая» | разговоры: три «голоса» на высоте речи, слоги и фразы (LFO), фильтры-форманты переключаются между гласными — слов нет |
| 3 | Метро | гул вагона: низкий шум, гудение 48/96 Гц, тонкий металлический свист | стук колёс: «та-дам» — две пары ударов на такт |
| 4 | Стройка | молоток: металлический звон + стук, 2–3 удара раз в такт или реже | механизм: низкие тона и шум с «пыхтящей» модуляцией громкости |
| 5 | Сигналы | громкоговоритель: «дин-дон-дин» через полосовой фильтр и эхо (далеко) | сирена: высота плавно ходит 620–1250 Гц |
| 6 | Птицы | щебетание: серии коротких высоких тонов со скольжением вверх | крики: протяжный тон «ки-ау» с вибрато |
| 7 | Дождь | капли: короткий тон со скольжением вверх + щелчок | ливень: широкая полоса белого шума + низкий розовый шум |
| 8 | Ветер | мягкий ветер: розовый шум, полоса медленно гуляет | порывы: узкая резонансная полоса (свист) + гул, громкость порывами |
| 9 | Растительность | шелест: мягкие всплески высокого шума | хруст: быстрые серии коротких щелчков + треск |
| 10 | Вода | ручей: шум воды + постоянные мелкие «бульки» | плеск: шумовой удар с закрывающимся фильтром + «плюх» |

Все звуки среды проходят через общий лёгкий ревербератор, чтобы звучать «в пространстве».

### Парные ползунки (строгая логика)

Функция `pairToGains(value)` в `state.js`, положение ползунка от −1 до 1:

- `|value| ≤ 0,08` — зона тишины, оба звука выключены;
- выше — звучит **только верхний**, ниже — **только нижний**;
- громкость = квадрат расстояния от края зоны тишины (0…1).

Отпущенный в зоне тишины ползунок встаёт ровно в центр, двойное нажатие — тоже в центр.
При переключении сверху вниз `updateAmbience()` сначала за 40 мс гасит старый звук и только
потом начинает поднимать новый — звуки пары никогда не смешиваются, щелчков нет.

### Барабаны

Бочка — `MembraneSynth`, малый — шум + короткий тон, клэп — три быстрых шумовых удара,
хэты — высокочастотный шум (короткий и длинный), щелчок — очень короткий высокий тон.

Рисунки в `patterns.js` записаны строками по 16 шагов: `.` — пауза, цифра 1–5 —
с какого уровня плотности звучит удар. Большая крутилка задаёт уровень 1…5.
Один цикл `scheduleRepeat` на шестнадцатые читает пресет и плотность на каждом шаге —
поэтому переключение пресета не запускает второй цикл.

## Запись и скачивание

Кнопка ▶ одновременно запускает звук и запись итогового выхода (оба голоса, среда,
барабаны, все эффекты — то, что слышно в колонках, со всеми изменениями по ходу игры).

**Почему не `Tone.Recorder`:** он записывает через `MediaRecorder` в WebM/Ogg/MP4
(разный формат в разных браузерах), а в Tone.js 15.1.22 его продолжение после паузы
не срабатывает. Поэтому в `recorder.js` используется стандартный браузерный
**AudioWorklet**: он получает те же сэмплы, что идут в колонки, и передаёт их в основной поток.
Пока инструмент на паузе, сэмплы не сохраняются — длинной тишины в файле нет.
При скачивании сэмплы упаковываются в **настоящий WAV** (PCM, 16 бит, стерео) —
расширение `.wav` соответствует содержимому.

- Время рядом с ▶ — длительность накопленной записи; полоска под ним — заполнение до предела 10 минут
  (10 минут WAV ≈ 110 МБ). При достижении предела инструмент ставится на паузу.
- Кнопка скачивания недоступна, пока записи нет. Во время подготовки — «Подготовка…».
- Скачивание во время игры сначала ставит паузу, чтобы запись корректно завершилась.
- Имя файла: `bitonika-ГГГГ-ММ-ДД-ЧЧ-ММ-СС.wav`. Запись хранится до сброса.

## Ссылка с настройками

Кнопка «поделиться» превращает `state` в JSON → base64url и кладёт в адрес после `#s=`.
Сервер не нужен. В ссылке: ноты и длительности, формы волн, громкости голосов,
10 парных ползунков, эффекты обоих голосов, пресет/плотность/громкость барабанов,
темп, общая громкость, время суток и **версия формата** (`v: 1`).

При открытии ссылки `sanitizeState()` проверяет каждое поле: неизвестные значения
заменяются начальными, числа ограничиваются диапазоном. Повреждённая ссылка
не ломает сайт — загружаются начальные настройки и показывается сообщение.
Звук по ссылке стартует только после нажатия ▶. Ссылка передаёт настройки, а не запись.
Если буфер обмена недоступен, открывается окно со ссылкой для ручного копирования.

## Сброс

Останавливает звук и запись, обнуляет время, удаляет запись, возвращает `DEFAULT_STATE`,
ставит ползунки среды в центр, обновляет все элементы и убирает настройки из адреса.
После сброса ▶ снова работает без перезагрузки страницы.

## Утро / день / вечер

Переключатель меняет только атмосферу фона (три слоя градиентов плавно сменяют друг друга)
и сохраняется в ссылке. Композицию он не трогает.

## Как менять звук

| Хочу… | Где |
|---|---|
| другие ноты голоса | `VOICE_NOTES` в `state.js` |
| другой характер голоса | `createVoice()` в `audio.js` — огибающая `envelope`, фильтр `filterEnvelope` |
| громче/тише голос | `level` в конце `createVoice()` |
| диапазоны эффектов | `effectParams()` в `audio.js` |
| громкость звука среды | первое число в `makeSound(0.9, …)` |
| характер звука среды | рецепт этого звука в `createAmbience()` (частоты фильтров, скорость LFO, вероятность `Math.random() > …`) |
| барабанный рисунок | строки в `patterns.js` |
| начальные настройки | `DEFAULT_STATE` в `state.js` (используется и при загрузке, и при сбросе) |
| диапазон темпа | `RANGES.tempo` в `state.js` |

После изменения звука полезно открыть `tests/audio-check.html`: он покажет уровни всех 20 звуков.

## Вёрстка

- Размеры макета записаны в «единицах макета» `--u` (1 единица = 1 px исходного макета).
  На ноутбуке `--u` подстраивается под высоту окна, чтобы всё помещалось без прокрутки;
  текст при этом не меньше 12 px. Это не масштабирование картинкой: элементы
  по-прежнему раскладываются через Grid/Flexbox.
- Уже 900 px — одна колонка с вертикальной прокруткой.
- Ползунки — обычные `<input type="range">` (мышь, касание и клавиатура работают сами);
  вертикальные повёрнуты через `writing-mode`. Крутилки — `role="slider"`: перетаскивание,
  колесо, стрелки, Home/End, двойное нажатие — значение по умолчанию.
- Рядом с элементом при изменении всплывает реальное значение параметра.

## Публикация на GitHub Pages

1. Загрузите содержимое папки в репозиторий (так, чтобы `index.html` был в корне).
2. **Settings → Pages → Build and deployment → Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт появится по адресу `https://<логин>.github.io/<репозиторий>/`.

Все пути относительные, Tone.js и шрифты лежат в проекте — внешние CDN не нужны.

## Что проверено

Проверки выполнены автоматически в Chromium 141 (без графического окна, через Playwright),
плюс `node tests/state.test.mjs`. Звук измерялся измерителями уровня и спектра, а не на слух.

**Пройдено (84 проверки в браузере + 29 модульных):**

1. Аудио не создаётся до нажатия ▶; после нажатия звучат оба голоса и барабаны.
2. Выключенные ноты дают паузы (после затухания хвостов эффектов — полная тишина);
   ползунок длительности меняет длину нот (доля звучания 0,35 → 0,89).
3. Четыре формы волны меняют тембр (спектральный центр: синус ≈ 600 Гц, треугольник ≈ 730,
   квадрат ≈ 1360, пила ≈ 1290); второй экземпляр голоса не создаётся.
4. Все 20 звуков среды слышны (пики −9,5…−21 дБ на своём канале), их пара при этом молчит (−∞).
5. Все ползунки в центре — тишина; зона тишины возвращает в центр; двойное нажатие — в центр;
   при резком переключении верх ↔ низ перекрытие громкостей пары = 0.
6. Пять пресетов звучат; переключение не добавляет циклов (число событий транспорта постоянно);
   плотность добавляет удары; темп меняет транспорт и время эха.
7. Эффекты: эхо природы меняется без изменения города; крутилки показывают значения выбранного
   голоса; искажение и плавность применяются; крутилка работает перетаскиванием и клавиатурой.
8. Пауза: выход затихает до −∞ (с хвостами), время записи не идёт; продолжение без удвоения.
9. Скачивание во время игры ставит паузу; файл — настоящий WAV 16 бит стерео; длительность файла
   совпадает с записью (9,16 с = 9,16 с); пауза 3 с в файл не попала; в файле есть звук,
   провалов тишины нет; время на экране совпадает.
10. Ссылка: «Ссылка скопирована»; в новой вкладке восстановлены волна, темп, ползунок среды,
    время суток, пресет, эффекты природы; звук не стартует сам, после ▶ использует эти настройки.
11. Повреждённая ссылка: сообщение, начальные настройки, адрес очищен, ошибок нет, звук запускается.
12. Три цикла старт → пауза → продолжение → двойные нажатия → сброс: число циклов не растёт,
    громкость не растёт (−15,0 / −14,4 / −13,9 дБ — разница от случайных звуков, не удвоение),
    после сброса тишина, зависших нот нет.
13. Все слои на максимуме: пик выхода −4,9 дБ (без перегрузки).
14. Вёрстка 1440×900 и 1280×832 — без прокрутки; 390×844 — одна колонка, ничего не выходит
    за ширину экрана; текст ≥ 12 px.
15. В консоли нет ошибок и предупреждений.

**Не проверено — нужно проверить вручную:**

- **Звучание на слух.** Я измерял уровни и спектр, но не слушал: насколько «разговоры»,
  «ливень» или «хруст» похожи на свои названия — решает только ухо. Балансы громкостей
  подобраны по измерениям и могут потребовать подстройки (`makeSound(…)`).
- Safari и Firefox (проверялся только Chromium), особенно вертикальные ползунки
