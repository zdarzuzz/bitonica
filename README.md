# Битоника

[Открыть синтезатор](https://zdarzuzz.github.io/bitonica/)

Битоника — веб-синтезатор города и природы. Два мелодических голоса сочетаются со звуками окружения и барабанными рисунками. Все звуки создаются программно с помощью Tone.js.

## Возможности

- Два голоса с независимой громкостью и четырьмя формами волны.
- Восемь шагов у каждого голоса: включение нот, длительность и перемещение плашек в нужном порядке.
- Двадцать звуков окружения в десяти переключателях. Верхнее и нижнее положения выбирают звук, центральное выключает пару.
- Пять барабанных пресетов с настройкой плотности, громкости и темпа от 70 до 150 BPM.
- Общие эффекты: искажение, эхо и реверберация. Регулятор плавности меняет атаку и затухание звуков.
- Запись исполнения до 10 минут с экспортом в стерео WAV.
- Сохранение текущих настроек в ссылке и сброс к начальному состоянию.

При открытии все ноты, звуки окружения и барабаны выключены. Звук и запись запускаются кнопкой воспроизведения. Переключатель времени суток меняет фон интерфейса.

## Звуковая схема

Голоса города и природы имеют собственные регуляторы громкости. Звуки окружения и барабаны проходят через отдельные шины. В общем миксе сигнал обрабатывается искажением, эхом и реверберацией, затем проходит через общую громкость, компрессор и лимитер. Итоговый сигнал поступает на выход, визуализацию и запись.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка интерфейса |
| `css/style.css` | Стили и адаптивность |
| `js/main.js` | Сборка интерфейса и обработка действий |
| `js/controls.js` | Ползунки, крутилки и переключатели |
| `js/state.js` | Состояние, проверка данных и ссылки с настройками |
| `js/audio.js` | Генерация и обработка звука |
| `js/patterns.js` | Барабанные рисунки |
| `js/note-reorder.js` | Перемещение нот мышью, касанием и клавиатурой |
| `js/recorder.js` | Запись и экспорт WAV |
| `js/vendor/` | Tone.js и лицензии библиотеки |
| `assets/` | Логотип, иконки и шрифты |
| `tests/` | Проверки состояния и звука |

## Технологии

HTML, CSS, JavaScript (ES-модули), Web Audio API, Tone.js 15.1.22, Canvas и AudioWorklet.

## Проверки

`node tests/state.test.mjs` — проверка настроек, порядка нот и ссылок. В браузере доступны `tests/tests.html` и `tests/audio-check.html`. Для локального просмотра нужен HTTP-сервер с поддержкой ES-модулей.

## Ресурсы

Шрифт Inter используется по лицензии SIL Open Font License. SVG-иконки Lucide — по лицензии ISC. Тексты лицензий находятся в `assets/fonts/`, `assets/icons/` и `js/vendor/`.
